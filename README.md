# Reprohackathon
### Pipeline 1: Persister cells RNA-Seq
The goal of the first pipeline is to reproduce parts of the analysis of Perusson and Van Bambeke's paper, *Intracellular Staphylococcus aureus persisters upon antibiotic exposure*, Nat Commun 11, 2200 (2020) (https://www.nature.com/articles/s41467-020-15966-7). 
The pipeline is done in Nextflow, and each process run in a Docker container published on DockerHub at ... .
The pipeline is divided in 4 major parts which we'll develop 
  1) Read clinning
  2) Mapping
  3) Read counts per gene
  4) Differential expression
